CÓDIGO · DAÑO

Daño con azar y defensa

// Factor aleatorio entre 0.85 y 1.15 sobre el daño base
export function rollDamage(baseDamage) {
  const factor = 0.85 + Math.random() * 0.3;
  return Math.round(baseDamage * factor);
}

export function calculateDamage(baseDamage, isDefending = false,
                                damageReduction = DEFENSE_REDUCTION) {
  if (!isDefending) return baseDamage;

  // Aplica reducción porcentual manteniendo al menos 1 punto de daño
  const reduced = Math.round(baseDamage * (1 - damageReduction));
  return Math.max(1, reduced);
}

export function applyDamage(card, damage) {
  const nextHp = Math.max(0, card.currentHp - damage);
  return { ...card, currentHp: nextHp, isDefending: false };
}
src/utils/battleEngine.js
  • ±15 % de variación: ningún combate es igual.
  • Defender reduce el golpe a la mitad…
  • …pero nunca baja de 1: siempre hay avance.
  • applyDamage devuelve una carta nueva y consume la defensa.

// Se llama al inicio de cada turno propio de la carta:
// el cooldown avanza una vez por turno
export function beginTurn(card) {
  if (card.specialCooldown <= 0) return card;
  return { ...card, specialCooldown: card.specialCooldown - 1 };
}

// dentro de getActions(card):
const nextTurn = card.turnsPlayed + 1;
let reason = null;
if (nextTurn < card.special.unlockTurn) {
  reason = `Disponible en el turno ${card.special.unlockTurn}`;
} else if (card.specialCooldown > 0) {
  reason = `Cooldown: ${card.specialCooldown}`;
}

SEGURIDAD · HASH + SALT

Nunca guardamos la contraseña

export function generarSalt() {
  return aHex(crypto.getRandomValues(new Uint8Array(16)));
}

export async function hashPassword(password, salt) {
  const datos = new TextEncoder().encode(`${salt}${password}`);
  return aHex(await crypto.subtle.digest("SHA-256", datos));
}

export async function verificarPassword(player, password) {
  if (!player?.passwordHash || !player?.salt) return false;
  return (await hashPassword(password, player.salt))
    === player.passwordHash;
}

CÓDIGO · SINCRONÍA

Escritura optimista

// Control optimista: solo se escribe si nadie cambió el estado
// desde la última lectura
async escribir(transformar) {
  if (this.enviando) return;
  this.enviando = true;
  try {
    const actual = await getMatch(this.match.id);
    if (actual.battleState?.seq !== this.state.seq ||
        estaTerminada(actual.battleState)) {
      return this.aplicarRemoto(actual);
    }
    const next = transformar(actual.battleState);
    if (!next) return;
    this.aplicarRemoto(
      await patchMatch(actual.id, parcheBatalla(actual, next))
    );
  } catch (err) {
    this.mostrarEstado(err.message);
  } finally {
    this.enviando = false;
  }
}
src/components/online/onlineBattle.js
  • Lee primero el estado actual del servidor.
  • Si seq cambió, el rival ya movió: se aplica lo remoto.
  • Si coincide, transforma y hace PATCH.
  • enviando evita doble clic mientras viaja la petición.
CÓDIGO · PASAR TURNO

Cambio de turno: una función pura

function pasarTurno(state, role, now) {
  const siguiente = rival(role);
  if (role !== state.firstTurn) state.round += 1;
  state.turn = siguiente;
  state.turnDeadline = now + TURNO_MS;
  const i = state[siguiente].index;
  state[siguiente].cards[i] = beginTurn(state[siguiente].cards[i]);
}
src/utils/onlineMatch.js
  • Recibe el estado y lo modifica solo en el clon que le pasan.
  • Reinicia el temporizador de 25 s del siguiente jugador.
  • Sube la ronda cuando termina el segundo en actuar.
  • Llama a beginTurn: así baja el cooldown del especial.
CÓDIGO · APLICAR ACCIÓN

Aplicar una acción: sin mutar

export function aplicarAccion(
  state, role, actionIndex, now = Date.now()
) {
  if (estaTerminada(state) || state.turn !== role) return null;
  const action = getActions(cartaActiva(state, role))[actionIndex];
  if (!action?.enabled) return null;

  const next = structuredClone(state);
  const enemigo = rival(role);
  const res = resolveAction(
    cartaActiva(next, role), cartaActiva(next, enemigo), action);
  // ... aplica el resultado ...
  next.seq += 1;
  next.timeouts[role] = 0;
  // ... si derrotó a la última carta: terminar(next, role) ...
  pasarTurno(next, role, now);
  return next;
}
src/utils/onlineMatch.js
  • structuredClone: el estado anterior nunca se muta.
  • Rechaza acciones fuera de turno o bloqueadas.
  • seq += 1 marca la versión para el control optimista.
  • Mismo motor para CPU y online.

const ESPERAS_MS = [2000, 4000, 6000, 8000, 10000];

// Render (plan gratuito) apaga el servidor tras inactividad:
// el primer arranque puede tardar ~1 min
async conectar() {
  this.setEstado("checking");
  let ok = await pingServer();
  for (const espera of ESPERAS_MS) {
    if (ok) break;
    this.estado = "waking";
    this.render();
    await new Promise((r) => setTimeout(r, espera));
    ok = await pingServer();
  }
  this.setEstado(ok ? "online" : "offline");
}

DECISIONES TÉCNICAS

Decisiones y sus límites

✔ Lógica pura y compartidaMismo motor para CPU y online; fácil de probar.
✔ Cero frameworksWeb Components y ES Modules nativos.
⚠ Polling, no tiempo realSimple y barato; latencia de 1.5 a 2 s.
⚠ JSON Server en RenderDisco efímero: los datos pueden perderse al reiniciar.
⚠ Seguridad básica/players expone hash y salt; el admin va en db.json.
⚠ Pruebas solo de lógicaNo hay pruebas de UI, API ni ranking.
